# Machine Rounds

An anesthesia machine and monitoring review game for ANES 1123 (Oklahoma City Community College, Anesthesia Technology program).

Students play ten stations as the anesthesia technologist on the early shift. Each correct decision releases a two digit code, which the student decodes on a personal printed key card to reveal a unique phrase.

## Hosting with GitHub Pages
1. Open **Settings > Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Share the published link with students.

## Note for instructors
This repository holds only the game. The key cards, phrases and answer key are kept offline, so a public repository does not reveal the phrases.
